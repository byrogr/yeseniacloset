# yeseniacloset

Sitio estático de Yesenia Closet, publicado con GitHub Pages en `https://byrogr.github.io/yeseniacloset/`.

- `index.html`: página del negocio. Es la URL de "sitio web" en el perfil de WhatsApp Business.
- `privacidad.html`: política de privacidad y nota de transparencia del asistente automático. Es la URL de "Política de privacidad" de la app de Meta, y `privacidad.html#eliminacion-de-datos` la de "Instrucciones de eliminación de datos".

La fuente del texto de la política es `docs/transparencia.md` del repositorio `yeseniacloset-chatbot`: si cambia allá, se actualiza aquí.

Antes de publicar, reemplazar todos los `[...]` (buscar `\[`) con datos validados con la dueña.
